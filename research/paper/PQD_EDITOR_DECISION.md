# PQD-001 Editor Decision

## Independent Views

### Researcher View

- Q06 converts a known data-vintage problem into a clean public-data measurement question for
  conditional factor evidence; a null is valuable.
- Q11 offers unusually transparent identification and undergraduate feasibility.
- Q03 addresses an economically intuitive crisis-risk tension.

### Referee View

- Q06 may be an application of real-time bond-predictability studies with no new mechanism.
- Q11 may be merely a mechanical calendar sensitivity exercise already familiar to practitioners.
- Q03 risks endogenous event definitions, small effective N and overlap with momentum-crash studies.

### Editor View

Invite only Q06 to a preregistration-design round. It has the best combination of public data,
paired identification, negative-result value and empirical-asset-pricing relevance. Reject it
immediately if a closest-paper search finds the same real-time-versus-revised vintage contrast for
factor state dependence, or if the regime variable cannot be constructed point-in-time without
researcher discretion. Q11 is the fallback Tier C project; Q03 needs stronger identification.

No empirical execution is authorized. Final OOS remains sealed.
